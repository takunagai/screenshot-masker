# 困ったとき

| 症状 | 対処 |
| --- | --- |
| `エラー: Tesseract が見つかりません` | `brew install tesseract tesseract-lang` で入れます |
| `エラー: Tesseract の実行に失敗しました（言語データ … が入っているか確認してください）` | `tesseract --list-langs` に `jpn` と `eng` があるか確かめます。無ければ `brew install tesseract-lang`。設定ファイルの `[ocr] lang` の綴りも確かめます |
| `エラー: 出力先が元画像と同じになるため中止しました` | `-o` で元画像と別のフォルダを指定します |
| `エラー: 処理できる画像（png / jpg）がありません` | 入力のパスと拡張子を確かめます。対応は `.png` / `.jpg` / `.jpeg` だけです |
| 隠したい文字が検出されない | `--preview` で確かめ、形が決まっていれば `[[detect.custom]]` に正規表現を足します（[設定ファイル](使い方.md#設定ファイル)）。形が決まらなければ annotate の `masks` で範囲を指定して隠します（[注釈を付ける](注釈を付ける.md)） |
| 隠さなくてよいものまで隠れる | `url` なら `allowed_domains` に残してよいドメインを足します。種類ごと不要なら `disabled` に書きます（[検出する種類](検出する種類.md)） |
| `注意: 日本語フォントが見つからないため…` | 設定ファイルの `[annotate]` の `font` に、日本語フォントのファイルのパスを書きます（[見た目の既定値](注釈を付ける.md#見た目の既定値)） |
| スクリプトが検出ありで止まる | 終了コード 1 は検出ありの意味です（[終了コード](使い方.md#終了コード)） |
| フックが画像を止めすぎる | 止めたくない種類を設定ファイルの `disabled` に書き、`screenshot-masker hook -c <設定ファイル>` で渡します（[フックで画像を止める](AIエージェントから使う.md#フックで画像を止めるclaude-code)） |
| 原因が分からないエラー | `--debug` を付けて実行すると詳細が表示されます |
