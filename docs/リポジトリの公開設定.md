# リポジトリの公開設定

確認日: 2026-11-08

## 現在の設定

- GitHub の公開範囲: public（2026-11-08 に private から切り替え。所有者の判断）
- 理由: ツールと同梱のスキルを、Claude Code のプラグインとして他の人にも配るため。カタログ（マーケットプレイス `takunagai`）は別リポジトリ `takunagai/claude-plugins` にあり、このリポジトリを参照する
- ライセンス: Apache-2.0（`LICENSE`）

## 公開前に確認したこと（2026-11-08）

| 範囲 | 方法 | 結果 |
| --- | --- | --- |
| 現在のファイル | 公開ガードの全体検査（`publication_guard.py --audit-index --ignore-repo-declaration`） | テスト内の架空のトークン・架空のユーザー名のパスだけ。値を表示しない分類で、全件が架空と判定 |
| 過去の全コミット（22 件） | コミットごとに一時 worktree を作り、同じ全体検査と分類 | 上と同じテストの架空値だけ |
| コミットの作者・コミッター | メールアドレスの種類だけを判定 | GitHub の noreply アドレス、またはクラウドセッションが使う Anthropic の共用 noreply アドレスのみ |
| コミットメッセージ | 個人パス・メール形式の件数 | 0 件 |
| 画像（`examples/` の 2 枚、過去の版を含む） | OCR で読んだ文字を検出規則にかけ、架空の印の有無だけを判定 | メール・トークンとも架空（例示用ドメイン等）。注釈済み画像は検出なし |
| GitHub 側 | PR・PR の参照・Issue・Release・Actions の実行 | PR 2 件（本文・コメントに該当なし。PR の参照は main の履歴に含まれる）。Issue・Release・実行は 0 件 |

確認していない範囲: 公開ガードと上の検査規則に当てはまらない種類の情報（文章の意味としての機密など）。

## 変更するとき・今後の注意

- 公開後は履歴も PR も誰でも見られる。過去のコミットに機密が入っていたと分かった場合は、削除より先に鍵の失効などを行う（ログや履歴の削除は失効の代わりにならない）
- 公開ガードは画像の中身を読まない。`examples/` などに画像を足すときは、架空の画面だけを使い、OCR で読んだ文字が架空であることを確かめる
- 非公開に戻すと、カタログ経由のインストールが作者以外は失敗するようになる
